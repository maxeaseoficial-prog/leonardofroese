# Caliber Elevated

Quero criar uma landing page premium para Leonardo Froese, fundador da Caliber Gestão Empresarial.

Esta página não deve ter aparência de página de curso, Hotmart ou landing page genérica.

Ela deve transmitir a sensação de uma empresa de consultoria de alto nível, moderna, tecnológica e voltada para empresários.

As principais referências visuais são:

 Apple

 Stripe

 Linear

 Vercel

 Framer

 Raycast

O design precisa ser extremamente refinado, minimalista e elegante.

Utilize muito espaço em branco (ou espaço negativo), tipografia forte, grids bem alinhados, animações suaves e microinterações sofisticadas.

O site deve parecer desenvolvido por um grande estúdio de design.
